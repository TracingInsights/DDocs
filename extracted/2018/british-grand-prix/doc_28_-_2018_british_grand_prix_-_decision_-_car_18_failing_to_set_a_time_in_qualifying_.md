# From The Stewards

## To The Team Manager,

Williams Martini Racing Document 28

Date 07 July 2018 Time 15:55 2018 BRITISH GRAND PRIX 5 - 8 July 2018 The Stewards have received a request from Williams Martini Racing to allow car 18 to start the race despite failing to set a time in qualifying. In accordance with Article 35.1 of the FIA Formula One Sporting Regulations, the Stewards grant permission for car 18, Lance Stroll, to start the race, as the driver has set satisfactory times in practice at this Event.
