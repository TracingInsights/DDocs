Date 28 April 2018 Time 18:52 2018 AZERBAIJAN GRAND PRIX 26 - 29 April 2018 The Stewards have received a request from Toro Rosso to allow car 28 to start the race despite failing to set a qualifying time within 107% of the fastest time in Q1. In accordance with Article 35.1 of the FIA Formula One Sporting Regulations, the Stewards grant permission for car 28, Brendon Hartley, to start the race, as the driver has set satisfactory times in practice at this Event.
