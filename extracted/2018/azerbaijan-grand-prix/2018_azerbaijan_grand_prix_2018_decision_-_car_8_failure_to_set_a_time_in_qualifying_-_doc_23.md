# From The Stewards

## To The Team Manager, Haas F1 Team

Document 23

## Date 28 April 2018

Time 18:53 2018 AZERBAIJAN GRAND PRIX 26 - 29 April 2018 The Stewards have received a request from Haas F1 Team to allow car 8 to start the race despite not setting a time in qualifying. In accordance with Article 35.1 of the FIA Formula One Sporting Regulations, the Stewards grant permission for car 8, Romain Grosjean, to start the race as the driver has set satisfactory times in practice at this Event.
